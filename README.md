# GeoQuest-research

GeoQuest-research is the data-collection tool of Preli Quest, a Bengali exam-preparation app. It verifies facts for educational maps.

**User agent**

```
GeoQuest-research/1.0 (https://conceptq2026-wq.github.io/geoquest-research/)
```

- **Fetches:** public pages and open-data APIs (for example official government websites, Wikipedia and Wikidata); one source per fact, cited.
- **Behaviour:** low request rate, one request at a time, robots.txt respected; any block, 403 or 429 makes it stop.
- **Contact for site operators:** please [open an issue](https://github.com/conceptq2026-wq/geoquest-research/issues). We will slow down or stop on request.

Page: https://conceptq2026-wq.github.io/geoquest-research/
