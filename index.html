GeoQuest-research user agent

GeoQuest-research is the data-collection tool of Preli Quest, a Bengali exam-preparation app. It verifies facts for educational maps.

User agent string

GeoQuest-research/1.0 (https://conceptq2026-wq.github.io/geoquest-research/)

What it fetches

  • Public pages and open-data APIs, for example official government websites, Wikipedia and Wikidata.
  • One source per fact. Every fact is cited.

How it behaves

  • Low request rate, one request at a time.
  • robots.txt is respected.
  • Any block, 403 or 429 response makes it stop.

Contact for site operators

Please open an issue at github.com/conceptq2026-wq/geoquest-research/issues. We respond there, and we will slow down or stop on request.
